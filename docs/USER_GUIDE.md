## 二、大屏 9 分区设置与统一网页管理后台

### 1. 设备大屏「设置 9 大分区」（无需电脑即可日常调参）
点击主页右下角 **「设置」**（或直接对设备说 *「你好小智，打开网络设置 / 打开天气设置」*）：
- **显示 / 声音**：丝滑调节亮度（支持环境光自适应）、深浅色主题、屏幕旋转方向、设备音量，一键开关 **AirPlay 投屏** 与 **蓝牙音箱模式**。
- **网络**：直接在屏幕上扫描附近 Wi-Fi 选网填密码连接，或手机扫描右侧二维码直达统一管理后台。
- **小智 / 对话**：多选唤醒词、调节唤醒灵敏度与连续追问时长、切换回答模型与 14 种免费 EdgeTTS 音色、查看近期对话。
- **天气 / 音乐 / 学习 / 系统**：**直接输入拼音（如 `beijing`、`suzhou`）或汉字实时搜索全国县区市**设置主页天气与最多 8 个常看城市；切换在线无损音质；查看 CPU 温度、内存与存储占用，安全重启服务或关机。

### 2. 统一网页管理后台（`http://<设备局域网IP>:18091/admin/`）
- **初始账号密码**：用户名 **`admin`**，密码 **`admin`**（首次安装自动创建，后续升级绝不覆盖；可通过网页右上角或 SSH `printf 'admin:新密码\n' | sudo /usr/local/sbin/thinksmart-set-admin-password` 修改）。
- **内外网三通道门控**：默认仅限家庭局域网访问；公网入口默认处于 **`外网:关`**（HTTP `403`），仅在管理员内网登录后台手动打开开关后放行。
- **整机一键备份与换机恢复**：在后台「系统与设备 → 整机配置备份导出与恢复」可一键导出 **脱敏分享备份包**（自动剥离所有密钥与登录态）或 **完整迁移备份包**（含在线热备的 `chat.db` 对话记忆、QQ 登录态、闹钟、城市与全部密钥），上传备份包即可经 SHA256 校验原子恢复。

## 三、AI 拍题黑板老师（`/tutor/`）与硬件使用要点

1. **两种出题与伴学方式**：
   - **手机拍照传题**：手机访问 `http://<设备局域网IP>:18091/tutor/`（或扫讲题页二维码），支持整页作业上传至大屏作业夹、四角透视裁边、去阴影增白，拖动绿框逐题开启苏格拉底分步黑板精讲。
   - **USB 高拍仪俯拍 + 静默伴写 + 自助听写**：外接高拍仪对准书桌作业本，停笔数秒后后台静默批改整页并定位错因步骤（零语音打扰），同时支持中英文单词表拍照提取自助报听写与拍纸秒批。
2. **硬件摆放与供电红线**：
   - 强烈推荐 **竖版立式（`800×1280`）** 摆放（重力感应自动旋转）；
   - 外接 **USB 高拍仪**或 **U 盘**时，**必须接入带独立 5V/PD 外接电源的有源 USB Hub**，切勿用无源分线器直插底部 Type-C 口。
3. **大模型选型建议**：
   - **小智语音主模型（重在首字延迟 `< 0.6s`）**：推荐 `deepseek-chat`、阿里云 `qwen-flash` / `qwen-plus`、智谱免费 `glm-4-flash` 或豆包轻量模型（切勿将慢思考模型设为日常语音主模型）。
   - **AI 讲题 3 档独立模型（重在看图 OCR + 几何推理）**：主力快讲推荐 `qwen-vl-max` / `qwen-vl-plus` / `glm-4v-flash` / `gpt-4o`；深度推理档推荐 `deepseek-reasoner` / `qwen3-max`；兜底备份填入另一厂商高可用端点。
   - **可选 Apple Silicon Mac 本地算力端（`mac-companion/`）**：运行 `bash mac-companion/install-mac.sh` 可在 M1/M2/M3/M4 Mac 上启用本地 `Qwen3-ASR` + `Qwen3-TTS` 流式语音克隆与 `Qwen3.5-9B` 端到端加密伴学视觉模型。
