## 二、统一管理后台、AI 讲题设置与硬件实操指南

### 1. 统一网页管理后台（`http://<设备局域网IP>:18091/admin/`）

> [!IMPORTANT]
> **初始登录凭据与内外网访问策略（默认已自动配置，二次升级不覆盖）**
> - **初始用户名**：`admin`
> - **初始密码**：`admin`
> - **默认仅限内网登录**：为了防止管理面直接暴露在公网，`/admin/` 出厂默认只允许家庭局域网（如 `192.168.x.x` / `10.x.x.x`）及可信本地回环访问。
> - **外网默认关闭，可一键手动开关**：页面顶部与左下角均显示实时外网门控开关（默认状态为 **`外网:关`**，此时所有经公网隧道请求 `/admin/` 会直接被拦截返回 HTTP `403`）。当您确实需要在外网调整配置时，在管理后台点击 **`外网:关` → 手动切换为开启**；现有反向隧道免密登录规则不受影响。

**首次登录推荐配置流**：
1. 在局域网内用手机或电脑浏览器打开 **`http://<设备局域网IP>:18091/admin/`**，输入初始用户名 **`admin`**、密码 **`admin`** 登录（建议第一时间在右上角账号菜单中修改强密码，也可通过 SSH 执行 `printf 'admin:新密码\n' | sudo /usr/local/sbin/thinksmart-set-admin-password` 修改）。
2. 进入 **「设置 → 大模型」**：
   - 选择小智对话主模型厂商（如 DeepSeek / 阿里云百炼 / 智谱 / 火山豆包 / 自定义兼容端点）并填入 `API Key`，点击「保存并应用」。
3. 进入同一页面下方的 **「AI 拍题黑板老师」**：
   - 填入或一键读取**讲题专用大模型**（`主力快讲模型`、`深度推理模型`、`兜底备份模型`）并点击「测试讲题模型」确认连通（详情见下文第 2 节）。
4. 进入 **「设置 → 语音」**：
   - 无本地 Mac 时保持默认 **`本机内置 EdgeTTS`**（免 Key 14 种音色）+ **`本机离线 Sherpa-ONNX`**（本机 CPU 离线中英识别），亦可填写火山引擎豆包等云端密钥或 Mac 语音克隆地址。
5. 进入 **「设置 → 天气与搜索」**：
   - 按需写入和风天气与联网搜索密钥，随时在网页可视化管理**留言板、倒数日、可视对讲、学习陪伴、本地歌曲与 Clash 代理**。

*(注：旧版小智原生底层控制台 `http://<设备局域网IP>:16688/admin` 仍保留作为底座备用，日常推荐统一使用 `:18091/admin/` 一站式控制所有服务。)*

### 2. AI 拍题黑板老师（`/tutor/`）· 2 种出题方式、竖版推荐与供电 USB Hub

#### ① 两种做题 / 讲题输入方式

| 方式 | 入口与操作流程 | 最适合的场景 |
| --- | --- | --- |
| **方式一：手机拍照传题** | 在电脑/手机打开 `http://<设备局域网IP>:18091/tutor/`（或用微信/系统相机扫描设备「手机拍题」标签页上的二维码），直接拍照、四角透视裁边、增白去阴影，点「发送黑板精讲」推上 ThinkSmart View 大屏。 | 临时拍错题本、试卷大题、课外压轴题；家里任意角落随手一拍就能推屏精讲与举一反三。 |
| **方式二：USB 高拍仪俯拍 + 静默伴写** | 将 USB 高拍仪平拍对准书桌作业本：切换至设备屏幕「高拍仪拍题」页，可**手指拖动绿框选中单题精讲**，或开启 **「静默伴写」** —— 自动盯防整页作答、停笔数秒后在后台静默批改，**不语音打扰写作业**，仅在卡片标注 `⚠️ 建议自查` 与精准出错步骤。 | 晚上独立写一整页数学/理化/英语作业时全程静默陪写与错题自动收集。 |

#### ② 硬件摆放与供电强建议（必看）

1. **强烈推荐使用「竖版立式 `800×1280`」摆放**：
   - 设备竖立放在桌面支架上时，底部 Type-C 接口位于最下端方便走线，不会挡住桌面书本空间；
   - `800×1280` 纵向画幅可以同时完整展示**原题题干 + 几何动态黑板 SVG + 多步启发选项/错因定位**，浏览竖排作业与高拍仪全页清单比横屏舒适得多；
   - 系统通过机身 `BMA253` 重力传感器自动感知横竖摆向并旋转 UI，您也可以在黑板顶栏点击方向按钮手动固定竖版或横版。
2. **外接高拍仪、U 盘务必使用「带独立外接供电的 USB Hub」**：
   - Lenovo ThinkSmart View 底部仅有一个 Type-C 接口，OTG 反向供电电流裕量较小；如果直接把无源拓展坞 + UVC 高拍仪（通常自带补光灯与对焦马达）或 U 盘插上去，很容易出现电压跌落导致**高拍仪反复重连、黑屏无图或 U 盘掉盘**；
   - **请务必串联一个带独立 5V / PD 电源适配器的有源 USB Hub**（高拍仪/U 盘插有源 Hub，同时有源 Hub 还可给机器供电或保证数据口稳定）。系统自带 `thinksmart-usb-host` 与 `thinksmart-usb-watchdog` 看门狗会自动守护 xHCI 控制器与 UVC 摄像头恢复。

#### ③ 为什么推荐给 AI 讲题单独设置大模型？

- **默认继承行为**：如果您刚装好系统、尚未在后台配置「AI 拍题黑板老师」的模型列表，讲题服务（`thinksmart-tutor`）会**自动复用小智当前激活的大模型**（`selected_module.LLM`），保证开箱就能讲文字题和样本课。
- **为什么强烈建议单独配置**：
  - **小智语音对话**追求**极低首包延迟（`~0.3s`）**，适合选轻量快模型（如 `deepseek-chat`、`qwen-flash`、`glm-4-flash`）；
  - **AI 拍题讲题**需要做**图片手写体/公式 OCR 识别、严格按步骤输出动态几何 SVG 坐标绘图，以及初高中数理化严谨推导**——轻量化语音小模型往往没有多模态看图能力，或复杂几何辅助线推理容易出错！
- **推荐 3 档分工配置（在管理后台 `http://<设备IP>:18091/admin/` → 设置 → 大模型 → AI 拍题黑板老师 中填入）**：
  1. **主力快讲模型（Fast）**：建议选择兼顾速度与看图能力的模型（如 `qwen-vl-max` / `qwen-vl-plus`、`gpt-4o`、`gemini-2.5-flash` 或已配置网关兼容视觉+长上下文的中等模型），负责常规题、拍照认图与快速分步黑板渲染。
  2. **深度推理模型（Deep）**：建议选择高推理/思维链模型（如 `deepseek-reasoner`、`qwen3-max` 或高阶推理模型），专门点击屏幕上的「深度讲解」拆解几何压轴题、动点题与奥数题。
  3. **兜底备份模型（Backup）**：填入另一家厂商的高可用模型，当主力线路超时或限流时系统自动无缝回退，确保孩子等题不卡死。

### 3. 和风天气 API 配置（点亮桌面天气卡片与日出日落换肤）

1. 登录 [和风天气开发服务控制台](https://console.qweather.com/)，查看专属 **API Host**（形如 `abc123xyz.re.qweatherapi.com`），创建项目获取 **API Key** 并开通免费开发订阅。
2. 可直接在管理后台 `http://<设备IP>:18091/admin/` → **「设置 → 天气与搜索」** 填入保存，或通过 systemd drop-in 写入（升级不覆盖）：
   ```bash
   sudo mkdir -p /etc/systemd/system/thinksmart-home.service.d
   sudo tee /etc/systemd/system/thinksmart-home.service.d/local.conf >/dev/null <<'EOF'
   [Service]
   Environment=QWEATHER_API_HOST=您的专属域名.re.qweatherapi.com
   Environment=QWEATHER_API_KEY=您的和风天气API_KEY
   Environment=WEATHER_DEFAULT_CITY=北京
   Environment=WEATHER_EXTRA_CITIES=上海,广州,深圳
   EOF
   sudo systemctl daemon-reload && sudo systemctl restart thinksmart-home.service
   ```

## 三、大模型选型与安装建议（纯云端方案 vs 本地 Mac 方案）

### 方案 A：无本地 Mac —— 纯云端推荐组合（强烈推荐 90% 用户）

1. **小智语音对话主模型（重在 TTFT < 0.6 秒 & 稳健 Tool Calling）**：
   - **DeepSeek (`deepseek-chat`)**：中文理解准确、函数调用稳，同一 Key 可同时支持联网搜索。
   - **阿里云百炼 (`qwen-flash` / `qwen-plus`)**：国内节点首字延迟极低（`~250ms`），体验流畅。
   - **智谱 BigModel (`glm-4-flash`)**：官方长期**完全免费**开放，控音乐、问天气与基础对话零成本。
   - **火山方舟 (`doubao-seed-2-0-lite-260215`)**：回复简练口语化，适合自然陪伴。
   - *避坑提示*：小智日常语音助手**不要**设成慢思考模型（如 `deepseek-reasoner`），否则喊完话会卡住十多秒！慢思考模型应放到 **AI 讲题的「深度推理」档位**。
2. **AI 拍题黑板老师模型（重在看图 OCR + 几何推理，在 `:18091/admin/` 单独配）**：
   - **看图拍题主力**：阿里云百炼 `qwen-vl-max` / `qwen-vl-plus`（对中文印刷体、手写算式与几何图识别极准），或智谱免费多模态 `glm-4v-flash` / 海外 `gpt-4o` / `gemini-2.5-flash`。
   - **难题深度拆解**：`deepseek-reasoner` / `qwen3-max` / 高阶推理模型（配在讲题 3 档中的「深度推理模型」即可，不影响语音助手响应速度）。
3. **本机自带免费语音识别与语音合成（开箱即用）**：
   - **离线识别 `SherpaXASR`**：机身预装 `167 MB` INT8 中英双语带标点识别模型 + `SileroVAD` + 唤醒词模型，**断网可用、0 API 费用**。
   - **内置合成 `EdgeTTS`**：内置微软 `EdgeTTS` 14 种中文音色（晓晓/云希/云夏/方言等），且家庭留言播报、番茄专注与学习提醒会自动复用选定音色。
4. **「AI 学习坐姿陪伴」无 Mac 纯云端跑法**：
   - 可直接在联想设备本机运行纯标准库 [`vision_bridge.py`](../mac-companion/study-vision/vision_bridge.py) 转发到智谱免费 `glm-4v-flash` 或百炼 `qwen-vl-plus`。

### 方案 B：有常开 Apple Silicon Mac（M1/M2/M3/M4）—— 本地算力分档建议

| Mac 统一内存 | 推荐开启组件 | 说明 |
| --- | --- | --- |
| **8 GB** | **仅开 `voice` 主进程**（`Qwen3-ASR-1.7B-8bit` + `Qwen3-TTS-1.7B-8bit`） | 常驻 `~4 GB`；学习陪伴与 AI 讲题视觉走云端，勿并发启动本地 `Qwen3-VL-8B`。 |
| **16 GB（黄金甜点）** | **`voice` + `tts2` 休眠副进程 + `Qwen3-VL-8B-Q4_K_M`** | 平时仅占 `~4.5 GB`，学习监测开启时峰值 `~10.5 GB`，10 分钟无请求自动休眠卸载显存；对话与讲题高阶推理可走云端。 |
| **24 GB ~ 32 GB+** | **全套 `mac-companion` + 本地 `Ollama` / `LM Studio` 模型** | 在小智/讲题后台添加自定义本地地址 `http://<Mac局域网IP>:11434/v1` 即可实现全屋离线大模型闭环。 |
